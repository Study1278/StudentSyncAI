StudentSync AI — Setup Guide (Fresh Machine)

Follow these steps in order on a brand-new Windows laptop with nothing installed. Every command is copy-pasteable into PowerShell or the VS Code terminal.

1 Install the required tools

Skip any step where the tool is already installed.

Also install the Python extension inside VS Code: Extensions panel (left sidebar) → search "Python" (by Microsoft) → Install.

2 Get the project onto your machine

Open a terminal (VS Code → Terminal → New Terminal), navigate to wherever you want the project folder, then:

git clone https://github.com/Study1278/StudentSyncAI.git
cd StudentSyncAI

Then open this folder in VS Code: File > Open Folder → select StudentSyncAI.

3 Create and activate a virtual environment

python -m venv venv

Windows PowerShell activation:

venv\Scripts\activate

If you get a "running scripts is disabled" error, run this first, then try activating again:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

You should see (venv) appear at the start of your terminal line — this means it worked.

Important: venv stores absolute file paths internally. If you ever move or rename the project folder, delete venv (Remove-Item -Recurse -Force venv) and recreate it fresh with the two commands above — don't try to reuse a moved one.

4 Install all project dependencies

With (venv) active:

pip install -r requirements.txt

This reads requirements.txt and installs every package at the exact version this project was built with — no guessing, no version conflicts.

5 Set up your environment secrets

Create a new file in the project root named exactly .env (no filename before the dot). It is never included in the GitHub repo (see .gitignore), so you must create it fresh every time you set up on a new machine.

Paste this template in, then fill in your own values:

DATABASE_URL=your_postgresql_connection_string_here
SECRET_KEY=your_random_secret_key_here
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=60

Getting DATABASE_URL:

  • Go to neon.tech, sign in (or create a free account)
  • Open your project → click Connect → copy the full connection string
  • If this is a brand-new database, your tables will be created automatically the first time you run the server (see Step 6)

Generating a fresh SECRET_KEY:

python -c "import secrets; print(secrets.token_hex(32))"

Copy the output and paste it as your SECRET_KEY value.

Never commit .env to GitHub, never share it, never paste it into a chat — it contains your database password and your JWT signing key.

6 Run the server

uvicorn app.main:app --reload

You should see:

Uvicorn running on http://127.0.0.1:8000
Application startup complete.

This also automatically creates any missing database tables in your Neon database on first run (via Base.metadata.create_all() in main.py).

Open your browser to:

http://127.0.0.1:8000/docs

This is the interactive API testing page (Swagger UI) — you can register a user, log in, and test every endpoint directly from here.

7 Quick smoke test

  1. POST /users/register — create a test user
  2. POST /users/login — log in, copy the access_token from the response
  3. Click the green Authorize button (top of the page) → paste the raw token → Authorize → Close
  4. GET /users/me — should return your user info with a 200 status

If all four steps succeed, your setup is fully working end to end.

Daily workflow (after setup is done once)

Every time you come back to work on the project:

cd StudentSyncAI
venv\Scripts\activate
uvicorn app.main:app --reload

That's it — no need to reinstall anything unless you pulled new changes that added new dependencies (in that case, rerun pip install -r requirements.txt after pulling).

Keep this file up to date as the project grows — if setup steps change, update this guide in the same commit.
